평탄화는 사영이다 — 계보를 따라서 Flattening is a projection — following the genealogy

새 정리가 아닙니다. 70년 된 정리입니다. 이 노트는 그 정리를 1955년 Mealy 기계에서 출발해 Lean 4 기계 검증 증명까지, 누가 언제 무엇을 했는지 따라가며 배웁니다. This is not a new theorem. It is a 70-year-old one. This note follows it from Mealy machines in 1955 to a machine-checked Lean 4 proof, tracking who did what, and when.

이 저장소는 노벨티를 주장하지 않습니다. 모든 재료가 교과서에 있습니다. 여기서 주장하는 것은 두 가지뿐입니다 — 전부 기계 검증되었다는 것, 그리고 한계까지 정리로 증명했다는 것. 교육적 가치는 결과가 아니라 경로에 있습니다. This repository claims no novelty. Every ingredient is textbook. It claims exactly two things — that everything is machine-checked, and that the limitations are proved too. The pedagogical value is in the route, not the result.

1계보Genealogy

굵은 점은 이 저장소가 직접 의존하는 마디입니다. Filled dots are the nodes this repository directly rests on.

  1. 1955
    Mealy machine — G. H. Mealy
    X × S → Y × S. 이 저장소의 ThreadCat이 정확히 이것입니다. 모나드보다 10년 빠릅니다. X × S → Y × S. This repository's ThreadCat is exactly this — a decade before monads.
  2. 1962
    Lawvere — the category Stoch
    Kleisli 범주가 일반적으로 도입되기도 전에 확률 쪽 사례가 먼저 나왔습니다. The probabilistic instance appeared before Kleisli categories existed in general.
  3. 1965
    Kleisli — Every standard construction is induced by a pair of adjoint functors
    Kl(G∘F)(X,Y) ≅ C(FX,FY). 같은 해 Eilenberg–Moore가 독립적으로 대수 범주를 구성했습니다. 이 정리가 상태 모나드의 Kleisli 사상을 Mealy 기계와 이어줍니다. Kl(G∘F)(X,Y) ≅ C(FX,FY). Eilenberg–Moore independently gave the algebra category the same year. This is the theorem that links state-monad Kleisli arrows to Mealy machines.
  4. 1968
    Karoubi envelope / idempotent completion
    split idempotent가 표준 도구가 됩니다. Tη ∘ μ의 멱등성이 사는 곳입니다. Split idempotents become a standard tool. This is where the idempotence of Tη ∘ μ lives.
  5. 1982
    Giry — Stoch as a Kleisli category
    분포 모나드. 선형화가 0–1 행렬로 무너지지 않는 첫 사례. The distribution monad — the first case where linearisation does not collapse to 0–1 matrices.
  6. 1991
    Moggi — Notions of computation and monads
    상태 모나드가 계산 효과 의미론의 표준이 됩니다. 이듬해 Wadler가 대중화하고 Haskell에 들어갑니다. The state monad becomes the standard semantics of effects; Wadler popularises it the next year, into Haskell.
  7. 2003
    –08
    Pattinson; Bonsangue–Rutten–Silva
    Mealy 기계를 M(S) = (B × S)A의 coalgebra로 보는 관점. Mealy machines as coalgebras of M(S) = (B × S)A.
  8. 2016
    Oliveira & Miraldo — Keep definition, change category
    “Mealy 기계 = 상태 모나드의 Kleisli 사상”을 명시합니다. 이 저장소 2장의 정리가 바로 이 문장입니다. States explicitly that Mealy machines are the Kleisli morphisms of the state monad — this repository's §2 theorem.
  9. 2020
    Fritz — Markov categories
    확률 쪽의 현대적 정리. 선형 모델이 실제로 내용을 갖는 영역. The modern synthesis on the probabilistic side — where a linear model genuinely carries content.
  10. 2025
    Effectful Mealy Machines (CALCO 2025); Markov kernels in Mathlib
    여전히 활발합니다. 죽은 분야가 아니라 잘 측량된 분야입니다. Still active. Not a dead field — a well-surveyed one.

2수학, 다섯 단계The mathematics, in five steps

단계 0 — 왜 “μ ∘ μ = μ”는 문장이 아닌가Step 0 — why “μ ∘ μ = μ” is not a statement

μ : T² ⇒ T는 서로 다른 두 함자 사이의 사상입니다. 정의역과 공역이 다르므로 멱등일 수 없습니다. 타입이 안 맞는 것이지, 거짓인 것도 아닙니다. 형식화가 가장 먼저 잡아내는 종류의 오류입니다. μ : T² ⇒ T maps between two different functors. Source and target differ, so it cannot be idempotent — it is not false, it is ill-typed. This is the first kind of error formalisation catches.

단계 1 — μ는 split epi다Step 1 — μ is a split epimorphism

μ ∘ Tη = id ⟹ e := Tη ∘ μ : T² → T² is idempotent

모나드 법칙 하나에서 한 줄로 나옵니다. T는 T²의 retract이고, e는 진짜 멱등원입니다 — 항등이 아님도 반례로 증명했습니다. One line from a single monad law. T is a retract of T², and e is a proper idempotent — not the identity, proved by counterexample.

Lean — St.mu_map_eta · St.collapse_idem · St.collapse_ne_id

단계 2 — Kleisli 사상은 Mealy 기계다Step 2 — Kleisli arrows are Mealy machines

Kl(T_S)(X, Y) ≅ Set(X × S, Y × S) (Kleisli 1965 + Mealy 1955)

이 단계가 선형 모델을 가능하게 만드는 전부입니다. Kleisli 사상 X → S → Y × S는 고차라서 벡터공간에 들어가지 않습니다. 커링을 풀면 평범한 집합 사이의 함수가 되고, 집합 사이 함수는 선형화됩니다. This step is what makes a linear model possible at all. A Kleisli arrow X → S → Y × S is higher-order and does not embed in a vector space. Uncurried, it is a function between plain sets, and those linearise.

주의 — 흔한 오해. 이것은 comonad − × S의 co-Kleisli 범주가 아닙니다. co-Kleisli hom은 X × S → Y입니다. |X|=|Y|=|S|=2에서 16 대 256으로 갈립니다. 맞는 말은 “− × S의 full image”입니다. (이 저장소도 한 번 틀렸습니다 — §4 참조.) Common trap. This is not the co-Kleisli category of the comonad − × S, whose hom-sets are X × S → Y — 16 against 256 when |X|=|Y|=|S|=2. The correct phrase is “the full image of − × S”. (This repository got it wrong once — see §4.)

Lean — threadEquiv · uncur · instFullUncur / instFaithfulUncur

단계 3 — 선형화는 충실하지만 충만하지 않다Step 3 — linearisation is faithful, not full

Lin S : Kl(T_S) ⥤ Vect_ℝ X ↦ ℝ[X × S] ≅ ℝ[X] ⊗ ℝ[S]

충실: 서로 다른 계산은 서로 다른 행렬을 갖습니다 — 행렬로 추론해도 됩니다. 충만하지 않음: 2·id는 어떤 계산의 선형화도 아닙니다 — 벡터공간은 엄밀히 더 큽니다. 두 방향 다 중요합니다. Faithful: distinct computations have distinct matrices, so reasoning through matrices is licensed. Not full: 2·id is the linearisation of nothing — the vector space is a strict enlargement. Both directions matter.

Lean — instFaithfulLin · two_smul_id_not_lin

단계 4 — 평탄화 = 그래프 위로의 사영Step 4 — flattening = projection onto a graph

두 단계를 잇기 전에는 두 번째 단계의 입력 상태가 자유 변수입니다. 그래서 무대는 겹친 배치 집합 (X × S) × S입니다. 평탄화란 그 자유 슬롯에 전이함수 σ를 대입하는 일입니다. Before the two stages are joined, the second stage's input state is a free parameter. The stage is therefore the doubled configuration set (X × S) × S, and flattening is substituting the transition function σ into that free slot.

μ ∘ t = expand t ∘ graph σ ← 정의상 성립 / true by definition Flat ∘ Sect σ = id π_σ := Sect σ ∘ Flat π_σ ∘ π_σ = π_σ π_σ ( δ_((x,s₁), s₂) ) = δ_((x,s₁), σ(x,s₁))
Lean — threadEquiv_mu · Flat_comp_Sect · proj_comp_proj · mu_eq_pi

단계 5 — 사영을 재어본다Step 5 — measuring the projection

dim ambient = |X|·|S|² rank π_σ = tr π_σ = |X|·|S| dim ker π_σ = |X|·|S|·(|S|−1)

rank와 trace가 σ에 무관합니다. 마지막 줄이 평탄화가 파괴하는 차원 수입니다. Rank and trace are independent of σ. The last line counts the dimensions flattening destroys.

4오류에서 배우기Learning from the errors

이 프로젝트는 네 번 틀렸습니다. 네 번 다 서로 다른 종류의 오류입니다 — 형식화가 무엇을 잡아주고 무엇을 안 잡아주는지 보여주기 때문에, 결과보다 이쪽이 더 교육적입니다. This project was wrong four times, in four different ways. That is more instructive than the result itself, because it shows what formalisation catches and what it does not.

5한계 — 주장이 아니라 정리로Limits — as theorems, not claims

MuEqPi/Limitations.lean에 있습니다. In MuEqPi/Limitations.lean.

① 상태 모나드와 무관하다. Tη ∘ μ의 멱등성은 모나드 법칙의 재진술이라 모든 lawful 모나드에서 성립합니다. ① Not about the state monad. The idempotence of Tη ∘ μ restates a monad law and holds for every lawful monad. Lean — mcollapse_idem · St.collapse_eq_mcollapse

② 선형대수와 무관하다. π_σ는 유한집합 위 멱등 함수의 선형화일 뿐입니다. 각 열에 1이 하나인 0–1 행렬이고, 스펙트럼은 자명하게 {0,1}이며, rank와 trace는 고정점 세기입니다. 벡터공간은 장부 정리입니다. ② Not about linear algebra. π_σ is the linearisation of an idempotent set map: a 0–1 matrix with one 1 per column, spectrum trivially in {0,1}, rank and trace counting fixed points. The vector space is bookkeeping. Lean — proj_eq_lin_setIdem · fixedPoints_setIdem

선형화가 0–1 행렬로 무너지지 않는 모나드 — Kleisli 사상이 확률행렬이 되는 분포 모나드 — 가 선형 모델이 스스로 내용을 갖기 시작하는 곳입니다. 다만 그곳은 빈 땅이 아니라 바가 더 높은 땅입니다 (Giry 1982, Fritz 2020). A monad whose linearisation does not collapse to 0–1 matrices — the distribution monad, whose Kleisli arrows are stochastic matrices — is where a linear model starts to carry content of its own. That is not empty land, though: it is well-populated (Giry 1982, Fritz 2020).
