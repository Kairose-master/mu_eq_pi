What is proved

Writing TSX = S ⇒ (S × X), the monad law μ ∘ TSη = id makes μ a split epimorphism. Uncurrying identifies Kleisli arrows with functions between configuration sets CX = S × X, which linearise. On the doubled configuration set one gets a retraction P and, for each transition function σ, a section iσ with P ∘ iσ = id. Hence eσ = iσ ∘ P is an idempotent linear operator — the projection onto the graph of σ — and flattening any nested computation factors through it.

Erratum, v1.1 → v2.0

§Correction
1The formula for μ applied a pair to an argument; the second projection was missing.
3F was defined on functions X → Y; to be a functor on Kl(TS) it must be defined on Kleisli arrows.
4The section was given only in the state-preserving case; the general theorem needs the family iσ. Also, P is not an instance of a projection V ⊗ W → W — no such natural map exists — but of the augmentation of a free module.
5The reshuffle isomorphism does not exist. It indexed a basis of ℝTSX by S × X, but TSX is a function set. For |S| = 2, |X| = 1 the two sides have dimension 8 and 4.
6Consequently F(μ) = θ⁻¹ ∘ P ∘ θ was ill-typed. Replaced by a factorisation of μ ∘ t for each nested Kleisli arrow, avoiding any attempt to linearise the object TSX.
8The Lean identifiers listed did not exist in the repository. Replaced by the actual names.

Scope

Two limits are themselves proved, in MuEqPi/Limitations.lean. The split idempotent is not a fact about the state monad — it holds for every lawful monad. And eσ is the linearisation of an idempotent map of finite sets, so its rank and trace count fixed points; the vector space is bookkeeping. A monad whose linearisation is not a 0–1 matrix — the distribution monad — is where a linear model would start to carry content of its own.
